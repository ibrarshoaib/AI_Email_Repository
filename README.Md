# AI Email Drafting Assistant

## Description
A Python-based AI assistant that generates professional emails using the OpenAI-compatible API.

## Features
- Cold Introduction emails
- Follow-up emails
- Proposal emails
- Customizable tone
- Simple command-line interface

## Requirements
- Python 3.10 or later
- OpenAI Python library

## Installation

```bash
pip install -r requirements.txt
```

## Usage

Run the project:

```bash
python main.py
```

## API Key

This project uses the Groq API for email generation.

The deployed Streamlit application is configured with a secure API key. If you clone this repository and run it locally, you must provide your own Groq API key for the application to work.
