# AI Email Drafting Assistant

## Description
A Python-based AI assistant that generates professional emails using the OpenAI-compatible API.

## Features
- Cold Introduction emails
- Follow-up emails
- Proposal emails
- Customizable tone
- Simple command-line interface

## Requirements
- Python 3.10 or later
- OpenAI Python library

## Installation

```bash
pip install -r requirements.txt
```

## Usage

Run the project:

```bash
python main.py
```

## API Key

Replace the placeholder API key in `llm.py` with your own API key.
